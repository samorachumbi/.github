# Support and working with me

Two ways in. Both reach a person — me, Samora — and neither requires an account, a form or a
developer's vocabulary.

## Email — for anything, and the fastest route

**samora@itikia.co.ke** — <mailto:samora@itikia.co.ke>

Use it for: *"we need one of these built for our team"*, a paid enquiry, a licence or invoice question, a
procurement form, a bug you cannot describe in a template, or a project that does not exist yet.

- Answered within **one business day**.
- If you would rather talk than type, say so and leave a number. A call is fine.
- Say what you are trying to get done and what you use today. That is what makes a useful reply possible —
  you do not need to know which tool or which term is the right one.

## GitHub issues — for a reproducible bug in a repo you can see

Open an issue on the repository itself when the report is public-safe and reproducible: it fails the same
way twice, a documented behaviour does not happen, a file type misbehaves.

Please do **not** open an issue for anything containing a credential, a customer's data, a private file or
a security problem. Use email, or see [SECURITY.md](SECURITY.md).

## What I do

I build and fix plugins for the DeepSeek Harness: media reading, browser control, planners, cost meters,
launchers. Small, self-contained tools that solve one real problem and come with the tests to prove they
work. If what you need is close to something already in my repositories, say so — a fork or an extension is
cheaper than a build from scratch.
