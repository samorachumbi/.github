# Security

## Reporting a vulnerability or a leaked credential

**Email samora@itikia.co.ke** with the subject `Security` — do not open a public issue.

<mailto:samora@itikia.co.ke?subject=Security>

Include what you did, what happened, and which project and version you were running. If you found a
credential published somewhere, tell me where it is rather than reposting it.

**What to expect:** an acknowledgement within one business day, an assessment, and a fix or mitigation as
fast as the severity warrants. This is a one-person operation, so the honest target is days for a genuine
issue, not hours — but you will get a reply and a decision.

## Scope

In scope for any project in this account: its code and its handling of local files, any hosted component
named in that project's README, and anything that could leak a user's data, a licence key or a payment
detail.

Out of scope: findings that require an already-compromised machine, social engineering, and automated
scanner output with no demonstrated impact.

## Please do not

Post a working exploit, a key, or someone else's data in a public issue, gist or paste site.
